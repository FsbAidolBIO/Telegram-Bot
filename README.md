# 🎨 Telegram Theme Bot (AI / Palette from Screenshot)

Умный Telegram-бот, который превращает **любой скриншот, фотографию, арт или обои** в полноценную тему оформления для **Telegram Android** (`.attheme`) и **Telegram Desktop / ПК** (`.tdesktop-theme`) с автоматическим определением гармоничной палитры, реалистичным предпросмотром и гибкой интерактивной настройкой.

---

## ✨ Возможности

- 📸 **Извлечение цветов из любого скриншота/фото**:
  - Алгоритм квантования и цветового анализа (Median Cut / HLS / Luminance).
  - Определение доминирующих оттенков, наиболее ярких акцентов (Vibrancy) и контраста (WCAG).
  - Автоматическое определение тёмного или светлого фона.
- 📱 **Генерация тем для Android (`.attheme`)**:
  - Полная поддержка более 100 параметров интерфейса Telegram (бабблы, заголовки, списки, плеер, меню).
  - Встраивание HD-обоев в бинарный блок `WPS` (установка темы и фона в 1 клик прямо в Telegram).
- 💻 **Генерация тем для Desktop / ПК (`.tdesktop-theme`)**:
  - Готовый архив `.tdesktop-theme` (ZIP) с `colors.tdesktop-theme` и фоновым изображением `background.jpg`.
  - Отдельный файл палитры `.tdesktop-palette` для кастомного редактирования.
- 🎛 **Гибкая интерактивная настройка (Inline кнопки)**:
  - 🌓 **Режимы:** Тёмная (`Dark`), Светлая (`Light`), Чистый черный (`AMOLED / OLED`).
  - 🎨 **Выбор акцента:** Переключение между найденными яркими цветами скриншота.
  - 🖼 **Варианты фона / обоев:**
    - `✨ Размытие (Blur)` — мягкий Gaussian Blur исходного изображения.
    - `🖼 Исходник` — оригинальный скриншот/арт.
    - `🌑 Затемнение` — исходное изображение с тёмным полупрозрачным оверлеем для максимальной читаемости.
    - `🌈 Градиент` — динамический диагональный градиент из цветов темы.
    - `🎨 Сплошной цвет` — строгий минималистичный фон.
  - 💬 **Стили бабблов (сообщений):**
    - `💬 Акцент` — яркий цвет для исходящих + нейтральная карточка для входящих.
    - `🎨 Оттенок` — мягкие тонированные цвета.
    - `⚡ Контраст` — два гармоничных акцентных цвета.
    - `▫️ Минимал` — спокойные системные тона.
  - ➖ / ➕ **Смещение яркости** — точная подгонка под комфорт для глаз (±30%).
  - ⚡ **Быстрые пресеты:** Неон, Пастель, Киберпанк.
- 🖼 **Интерактивная карточка превью**:
  - Рендеринг реального макета чата Telegram (заголовок, аватарки, входящие и исходящие бабблы, статус отправки, поле ввода).
  - Нижняя плашка со сэмплами и HEX-кодами всех ключевых цветов палитры.
- 📦 **Полный ZIP-пакет**:
  - Скачивание всех форматов (Android `.attheme`, PC `.tdesktop-theme`, `.tdesktop-palette`, обои для смартфона и ПК в высоком разрешении, инструкция).

## 🚀 Быстрый старт

### 1. Клонирование и настройка окружения

```bash
git clone https://github.com/FsbAidolBIO/Userbotttt.git
cd Userbotttt
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 2. Настройка переменных окружения

Создайте файл `.env` на основе примера:

```bash
cp .env.example .env
```

Отредактируйте `.env` и укажите ваш токен от [@BotFather](https://t.me/BotFather):

```env
BOT_TOKEN=123456789:ABCdefGhIJKlmNoPQRstuVWXyz
DEFAULT_THEME_MODE=dark
SESSION_TTL_SECONDS=7200
```

### 3. Запуск бота

```bash
python3 bot.py
```

## 📥 Как применить созданную тему в Telegram

### 🤖 На Android:
1. Скачайте файл `.attheme`, отправленный ботом.
2. Нажмите на него прямо в чате Telegram.
3. В открывшемся окне предпросмотра нажмите **«Применить тему»**.

### 💻 На ПК (Windows / macOS / Linux):
1. Кликните по файлу `.tdesktop-theme` в окне Telegram Desktop.
2. В появившемся окне нажмите кнопку **«Применить эту тему»** → **«Сохранить изменения»**.
