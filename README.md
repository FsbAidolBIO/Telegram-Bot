# 🎨 Telegram Theme Studio Bot (AI / Palette from Screenshot)

Умный Telegram-бот, который превращает **любой скриншот, фотографию, арт или обои** в готовую дизайнерскую тему оформления для **Telegram Android** (`.attheme`) и **Telegram Desktop / ПК** (`.tdesktop-theme`) с автоматическим определением гармоничной палитры, реалистичным предпросмотром, интерактивной сеткой цветов и экспортом дизайнерских карточек.

---

## ✨ Возможности

- 📸 **Интеллектуальный анализ скриншотов и артов**:
  - Алгоритм цветового квантования и вычисления хроматической насыщенности (Vibrancy & Contrast).
  - Автоматическое определение названий оттенков на русском языке (Лазурный, Янтарный, Неоново-розовый и др.).
  - Защита от монохромности: автогенерация гармоничных триад и комплементарных цветов.
- 📱 **Генерация тем для Android (`.attheme`)**:
  - Полная поддержка 100+ параметров интерфейса Telegram (бабблы, заголовки, списки, плеер, меню).
  - Встраивание HD-обоев в бинарный блок `WPS...WPE` с качеством 98% (4:4:4 Chroma). Установка в 1 клик!
  - Чёткие заметные белые никнеймы и имена собеседников.
- 💻 **Генерация тем для Desktop / ПК (`.tdesktop-theme`)**:
  - Готовый архив `.tdesktop-theme` (ZIP) с `colors.tdesktop-theme` и фоновым изображением `background.jpg`.
  - Отдельный файл палитры `.tdesktop-palette` для кастомного редактирования.
- 🎨 **Интерактивная сетка цветов в 1 клик**:
  - Прямые кнопки выбора ключевых цветов с цветными эмодзи (`[ 🔵 #00B4D8 ]`, `[ 🟣 #8E52EA ]`, `[ 🔴 #FF0055 ]`, `[ 🟢 #30A46C ]`).
  - Возможность отправить любой произвольный HEX-код сообщением (например, `#FF4500`).
- 🌌 **Цветовая атмосфера чата**:
  - 4 уровня насыщенности (Глубокая 22%, Умеренная 14%, Мягкая 6%, Выкл 0%).
  - Список диалогов и фоновые панели перенимают атмосферный оттенок арта вместо скучного серого/белого.
- 💬 **Стили сообщений**:
  - `Неон / Акцент` — яркий исходящий + гармоничный входящий.
  - `Двойной цвет (Dual)` — исходящие в основном акценте, входящие во втором ярком цвете из арта!
  - `Мягкий тинт (Pastel)` — нежные пастельные оттенки для комфорта глаз.
  - `Стекло (Glass)` — стильные полупрозрачные карточки.
- 📊 **Экспорт дизайнерской карточки палитры (PNG)**:
  - Скачивание карточки с образцами цветов, названиями оттенков, HEX и RGB кодами.
- ⚡ **JSON Токены и CSS Переменные**:
  - Экспорт структуры темы для разработчиков (`theme_tokens.json`).
- 📦 **Полный ZIP-пакет (All-in-One)**:
  - Скачивание всех форматов (Android `.attheme`, PC `.tdesktop-theme`, `.tdesktop-palette`, обои в исходном разрешении, PNG-карточка палитры, JSON токены, инструкция).

## 🚀 Быстрый старт (Zsh / Bash)

### 1. Клонирование и запуск в 1 команду:

```zsh
git clone -b arena/01a0e8f0-userbotttt https://github.com/FsbAidolBIO/Telegram-Bot.git
cd Telegram-Bot
./start.sh
```

## 🛠 Структура проекта

```
Telegram-Bot/
├── bot.py                     # Точка входа бота (aiogram 3)
├── config.py                  # Конфигурация и загрузка .env
├── start.sh                   # Скрипт быстрого запуска для Zsh/Bash
├── requirements.txt           # Зависимости Python
├── Dockerfile                 # Docker-образ
├── docker-compose.yml         # Docker Compose конфигурация
├── theme_engine/              # Движок генерации тем
│   ├── color_extractor.py     # Извлечение палитры, названий цветов и HLS/Luminance
│   ├── palette.py             # Построение гармоничной темы и атмосферы чата
│   ├── android_generator.py   # Сборка .attheme с WPS/WPE обоями
│   ├── desktop_generator.py   # Сборка .tdesktop-theme архивов
│   ├── wallpaper_generator.py # Беспотерьные фильтры обоев (4:4:4 Chroma)
│   ├── preview_generator.py   # Рендеринг карточки превью чата со встроенным шрифтом
│   ├── palette_card_generator.py # Генератор дизайнерской карточки палитры (PNG)
│   ├── json_exporter.py       # Экспорт JSON дизайн-токенов и CSS переменных
│   └── fonts/                 # Встроенные TrueType шрифты с поддержкой кириллицы
├── handlers/                  # Обработчики Telegram
│   ├── start.py               # Команды /start, /help, /random
│   ├── image_handler.py       # Обработка фото, файлов и HEX-кодов
│   ├── callbacks.py           # Интерактивные кнопки настройки и скачивание
│   ├── keyboards.py           # Интерактивные inline-клавиатуры
│   └── session_manager.py     # Сессии пользователей в памяти (TTL 2 часа)
└── tests/                     # Модульные тесты
    └── test_theme_engine.py   # Unit-тесты всех компонентов
```
